# Reproducibility protocol

1. **Inputs.** The registry workbook is read from `STROKE_DATA_PATH` (or `data/raw/`, git-ignored) and its MD5 is checked (`08541ef199c1656c184291f24b4cc3e3`); the dictionary MD5 is checked (`be778aa084720376bdc1c27392a260af`). Neither is ever written into `outputs/` or an archive. A synthetic fixture with the same 251 headers and codings (`scripts/make_synthetic_fixture.py`) lets the whole pipeline run without data.
2. **Environment.** `requirements.lock` pins the versions used for the reported run; `binder/`, `Dockerfile` and `.github/workflows/ci.yml` reproduce it online. Python ≥ 3.11.
3. **Runner and modes.** `run_all.py --mode {audit|observed|reconstructed|sensitivity|all}`; the reconstructed mode is gated by `config/outcome_definition.yaml → approval_state` and requires `--accept-provisional` while the registry has not verified the time origin; outputs are then stamped PROVISIONAL. No silent fallback.
4. **Determinism.** Seed 20261016 everywhere; nested CV folds are repeated stratified K-folds with fixed seeds; the imputer and models receive derived seeds. Two independent clean runs (2 Nov and 3 Nov 2026) produced byte-identical manuscript macros.
5. **Provenance.** `outputs/manifests/run_manifest.json`: SHA-256 of workbook, dictionary, every config, every source and script file, every output; software versions; mode; outcome-definition version and approval state; duplicate policy. `outputs/logs/execution_log.txt`: every step with exit code and duration, including any post-run correction.
6. **Verification.** `scripts/verify.py` (99 checks: cohort arithmetic, leakage controls, hard-coded statements vs outputs, LaTeX build, letter integrity, dictionary, journal format, citations) and `scripts/ticket_self_check.py` (every reviewer-derived ticket re-checked against the outputs, manuscript and letter) run at the end of every real-data run and fail the run on regression.
7. **Privacy.** Row-level intermediates are confined to `data/processed/` (git-ignored). `scripts/privacy_check.py outputs` must pass; archives are built from an allowlist and inspected.
8. **Manuscript.** Every number is a macro in `manuscript/tables/macros.tex` generated by `scripts/generate_manuscript_tables.py`; tables and figures are regenerated on every run; the response letter reads page/line numbers from the compiled `.aux`.
